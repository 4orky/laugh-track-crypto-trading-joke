A program that picks the funniest original one-line joke about crypto and trading life from fourteen candidates and writes it to `/output/entry.txt`:

> The group chat called it a generational buying opportunity, so I bought the top — and now the same chat calls it a generational learning experience.

## How to run

```sh
python3 main.py
```

## How the winner was picked

Fourteen original candidate jokes were each scored 0–5 on the judge's five criteria, in the judge's priority order (setup and turn, laugh, true trading-life detail, tight phrasing, repeatable on a second read), weighted 5, 4, 3, 2, 1. Candidates leaning on tired crypto tropes ("to the moon", "diamond hands", "buy the dip", "lambo"...) lose a point off their true-detail rating per trope phrase. The winner scored 73 of a possible 75; the runner-up, the sold-at-the-bottom joke, scored 68; the dip joke scored 70 raw but 67 after its trope penalty.

The winning line got a real second pass before it was locked in: the first draft joined the two halves with a flat "and now the group chat calls it..."; the revision puts an em-dash beat before the turn and says "the same chat" instead of repeating "the group chat", so the callback is tighter and the punchline — "a generational learning experience" — lands harder.
